## What I've worked on

- **Production AI:** Owned an end-to-end translation pipeline for multilingual public-safety alerts, with provider fallback, HTML-safe output, quality scoring, and Python model benchmarks. Built multi-provider LLM gateways and retrieval-based event classification.
- **MLOps and ML infrastructure:** Built SageMaker deployment pipelines with Terraform, reducing model deployment time by 40% and cloud spend by 20%. Hands-on experience with GPU workloads on Kubernetes, containerized inference, CI/CD, and observability.
- **Applied research:** Worked on glucose-response modeling using meal and lifestyle data, revised training-data collection from continuous glucose monitors, and supported production deployment of a meal-photo glucose-prediction workflow.
- **Agents and feedback loops:** Built an incident-response agent that investigates issues and implements fixes for engineer validation. Engineers' replies feed back into its behavior through a real-time feedback loop.
- **Speech and geospatial systems:** Worked on speech-to-text pipelines processing 20,000 audio clips per day, built a custom voice activity detector, and developed multilingual location extraction with consensus across geocoders. Contributed geographic KNN matching and caching to event deduplication.
- **Full stack products:** Built React/TypeScript workflow tools, backend APIs, and PostgreSQL-backed applications. Personal projects include a voice agent that calls businesses on users' behalf, an iOS learning app with AI-generated quizzes, and a React Native travel app.
